# 질문 기반 외부 문서 준비: P1·P2

이번 단계는 동네와 질문에서 검색어를 추출(P1)하고 외부 후보를 선별(P2)해 실제 본문을 색인한다. 답변 생성 P3·LangGraph·화면 연결은 아직 후속 단계다.

```powershell
.\.venv\Scripts\python.exe scripts/prepare_rag.py --item 1144010200 --question "공덕동의 교통과 공덕역에 대해 설명해줘"
```

기존 GMS_KEY·WIKI_CONTACT를 사용한다. 기본 결과 보고서는 Git에서 제외되는 storage/rag_prepare_report.json이다. 실제 사용자 질문·AI 검색어·선별 이유가 포함될 수 있으므로 개인 질문 보고서를 공유하지 않는다. docs/검증의 기록은 개발용 공개 지역 질문으로 실행했다.

## 처리 규칙

1. 공식 법정동 코드로 항목을 선택한다. 현재 자체 문서를 검증한 청운동·신당동·공덕동·연남동·역삼동만 지원한다. 미검증 동네를 비슷한 이름의 문서에 자동 연결하지 않는다.
2. 선택 항목의 자체 문서를 수집·색인한다. 짧은 본문도 제외하지 않으며 P1/P2 실패·선별 결과와 관계없이 먼저 저장한다. 원문이 없거나 검증에 실패한 경우는 성공으로 처리하지 않는다.
3. P1은 검색어 1~3개를 JSON으로 반환한다. 검색어는 100자 이내이며 실제 검색에는 전체 동네 이름을 함께 넣는다.
4. 위키백과 제목·요약 후보를 모으고 페이지 ID로 중복 제거한다. P2가 최대 3개를 ID·이유와 함께 선택한다. 후보에 없는 ID·중복·형식 오류는 거부한다. 후보가 없으면 P2를 호출하지 않는다.
5. 선택 문서 본문을 수집한다. 본문에 동네 이름과 서울 또는 자치구가 있어야 연결하며 동음이의 문서는 제외한다. 이 문자열 확인은 사실 검증이나 세밀한 지리 검증을 대신하지 않는다. 넓은 자치구 문서의 다른 동네 내용이 포함될 수 있으므로 이후 답변 생성에서는 해당 동네와 연결된 주장만 인용하도록 해야 한다.
6. 원문 판 URL·판 번호·판 시각·기여자 이력·CC BY-SA 4.0을 보존해 선택 동네 item_id에 외부 청크로 적재한다. 같은 문서도 다른 동네에 연결될 때 ID가 충돌하지 않는다.

질문·후보 요약·본문은 자료로 취급하고 그 안의 지시는 따르지 않도록 프롬프트에 명시한다. 구조화 출력 검증도 별도로 적용한다. 프롬프트는 rag_prepare.py의 P1·P2, 버전은 prepare-v1이다. 이 단계는 기존 대화 조건 추출 프롬프트와 별개다.

## 캐시와 실패 처리

자체 문서는 기존 해시 검증 캐시, 후보 검색·본문은 요청 파라미터별 JSON 캐시를 사용한다. 동일 요청은 네트워크 호출을 생략한다. P1·P2 AI 호출 자체는 매번 실행하므로 검색어가 달라지면 새로운 외부 검색이 발생할 수 있다. 캐시는 수동 갱신 전까지 최신 자료를 보장하지 않는다. 연락처가 없으면 외부 요청 사이 6.1초 간격을 두고, 연결 오류는 최대 3회 재시도한다.

중간 실패 시 이미 성공한 자체 문서·앞선 추가 문서 색인은 유지한다. 실패를 전체 준비 완료로 표시하지 않는다. 보고서에는 후보 수·선별 이유·본문 연결 제외 이유를 기록한다. DB·수집 캐시는 storage 아래에 있으며 버전 관리하지 않는다. 비교 실험 전에는 확장 완료 DB와 문서·청크 ID 및 판을 고정해야 한다.

## 실제 확인 (2026-10-22)

공덕동 질문에서 P1 검색어 3개, 검색 후보 6개, P2 선택 2개가 나왔다. 선택한 마포구·공덕역 문서 본문의 지역 연결을 확인하고 실제 임베딩·색인을 완료했다. 자체 문서는 기존 청크를 재사용해 추가 임베딩 0개였다.

[P1/P2 실제 실행 기록](검증/RAG_P1_P2_실제연결.json). 이는 품질·속도 정량 실험 결과가 아니다. 정식 유사도/MMR 비교와 RAG 전후 비교는 사전 평가 질문·정답 라벨과 고정 문서 집합으로 별도 수행한다.

확장 후 공덕동 검색 후보는 9개 청크이며 유사도·MMR 모두 외부 청크 3개와 필수 메타데이터를 반환했다. NumPy 배열의 MMR 중복도 계산 오류를 수정하고 실제 배열 테스트를 적용했다. [확장 후 검색 연결](검증/RAG_확장문서_검색연결.json).
