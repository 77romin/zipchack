# 2회차 셀프·상호 체크리스트 검토

검토일: 2026-10-23. 대상 코드: `31278ef`. 제공된 엑셀의 체크리스트 9~35행, 총 27항목을 대조했다. 원본 파일은 수정하지 않았다. 이 기록은 코드·자동 실행·기존 실제 연결 증빙을 통한 셀프 검토이며 타 교육생의 상호 점검을 대신하지 않는다.

판정은 원본의 통과·실패·미확인·해당없음을 사용한다. **실패는 필요한 기능이나 제출 증빙이 부족한 경우**, 미확인은 실행 증거가 충분하지 않은 경우다. 일부 구현이 있더라도 전체 조건을 충족하지 않으면 통과시키지 않았다. 이전 실제 실행 기록은 아래에 명시했고 이번 실행과 구분했다.

## 이번 실행 결과

- 전체 Python unittest: **161개 통과**, 33.231초. [실행 로그](2회차_테스트결과.txt).
- 현재 기본 DB: 메타데이터 467청크/467법정동, 외부 146청크/6개 item_id. 외부 item에는 서울 전체 공원 집계 식별자가 포함되므로 **6개 동네 자체 문서가 있다는 뜻은 아니다**. 자체 위키백과 스냅샷은 5동네다. 나머지 법정동 모두의 자체 문서를 확보한 상태도 아니다.
- 색인 dry-run: 동일 604문서(메타데이터467+공원132+자체 위키5)에 대해 기본605→변경617청크. 기본 DB의 외부146청크에는 추가 수집 자료가 있어 dry-run의 전체605와 직접 비교하지 않는다.
- 보안 검사: 현재 추적 파일에서 설정된 API 키 원문 미검출, `.env` 미추적. 키 값은 보고서와 로그에 기록하지 않았다.
- 이번 검토에서 운영 DB 삭제·키 변경·앱 기능 수정은 하지 않았다. 브라우저 전체 재시연·5문항 비교는 하지 않았다.

## 보완 순서

1. **필수 흐름:** Top-k 설정 노출, P1/P2 대화 연결 및 선택/제외 후보 전체 로그, 질문 단위 수집 캐시. 첫 질문·동일 질문 재실행을 기록한다.
2. **실패 상태와 출처:** 키 없음/색인 없음 구분, 위키/공식 통계/공식 시설 출처 종류와 이용 조건 표시, 외부 호출 경로별 간격·재시도 점검. README 현행화.
3. **재현 가능한 실험:** 정답·기준 출처가 있는 질문 최소5개 고정. 같은 모델·설정으로 no-RAG/similarity/MMR을 실행하고 정확성·인용·유보·전체 시간을 판정한다. 계산과 정답 판정을 보존한다.
4. **제출:** SVG 표·도표, 실제 그래프와 일치하는 UML, 번호별 화면 캡처, 최종 요구사항 대조표·엑셀 셀프 점검본. 이후 타인의 실제 상호 점검을 받는다.

단일 질문에서 서로 다른 답변·인용이 나왔다는 사실만으로 MMR의 정확도가 더 높다고 결론 내리지 않는다. 캐시가 있는 반복 요청과 첫 요청의 시간도 분리한다.
