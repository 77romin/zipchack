## 실험 해석

기준 자료로 답할 수 있는3문항에서 RAG 두 방식은3/3, 무근거 모델은0/3이었다. 무근거 모델이 모른다고 답한 것을 환각으로 판정하지 않았다. 자료 없는 현재 매물·실시간 재고2문항은 모두 미확인으로 답했다. 총 기준 부합은 무근거2/5·RAG 각5/5다. 이는 이 질문셋의 명시된 판정이며 일반적인 정확도100% 주장이 아니다.

유보 문장과 abstained flag가 일치하지 않는 사례도 있다. flag 정답은 두 RAG 방식 모두1/2였고 이를 별도 집계했다. 이 한계를 감추기 위해 결과를 수정하지 않았다. 초기 빈 답변·상태 문자열·비표준 인용 문제는 초기 기록과 수정본 실행을 구분해 보존했다.

## 아직 사람이 확인할 항목

셀프 점검의20번은 실제 사용자가 대기 시간을 수용할 수 있는지,25번은 전체 필수·선택 시나리오에 대한 타인의 독립 점검,27번은 타인의 실제 상호 체크리스트 작성이 남아 미확인으로 두었다. 자동 실행 결과로 타인의 평가·서명을 대신 작성하지 않았다. 자체 위키 설명 문서 범위는5동네이며467개 전체의 자체 문서 확보로 확대 해석하지 않는다.

증빙은 `RAG_최종실험/` 안의 JSON·CSV·SVG·번호별 PNG와 기존 지도/추천 캡처를 함께 본다. 기록 열람 화면은 `scripts/view_verification.py`이며 저장된 실제 결과를 표시하는 화면이다. 캡처가 모델의 새 호출 화면인 것처럼 표시하지 않는다. 운영 서비스는8501, 별도 기록 열람은8503이다.
