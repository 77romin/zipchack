# 대화와 지도 탐색 개선

## 대화

월세·전세 유형과 필요한 예산이 있으면 직장·통근 수단·통근시간을 모두 입력하지 않아도 실거래 후보를 조회한다. 공원·따릉이·연령 선호에 대한 추가 답변도 진행 조건으로 요구하지 않는다. 질문 순서와 관계없이 입력한 변경 사항을 계속 병합한다. 직장 위치가 없으면 직장 기준 지도·통근 비교는 수행하지 않는다.

실거래 API의 조회 범위인 자치구·계약월·주택 유형은 여전히 확인한다. 이를 임의로 채워 다른 범위를 조회하지 않는다. 예산이 없으면 예산 충족 후보라고 표시할 수 없으므로 필요한 금액은 확인한다. 사용자 질문 의도 전반을 자유롭게 답하는 통합 에이전트로 바뀐 것은 아니며, 동네 지식 질문은 별도 RAG 질문 영역을 사용한다.

## 사이드바와 지도

사이드바는 최초 접속 시 접혀 있고 Streamlit의 펼치기 버튼으로 직접 조정할 수 있다. 브라우저가 기존 표시 상태를 유지하면 새 세션에서 기본값이 적용된다.

선택 동네 대표점 주변에 반투명 500m 원을 그린다. 원을 클릭하면 과거 거래 예시·따릉이 자료 확인 상태·대표점 500m 이내 대여소 수·조회된 주민등록 연령 구성을 카드로 표시한다. 거래 예시는 보증금·월세를 같은 계약에서 가져온다. 현재 호가·매물 존재·실제 보행거리를 의미하지 않는다.

상단 지도 필터에서 따릉이·주변 시설 레이어를 각각 켜고 끌 수 있다. 연령 필터는 현재 선택 법정동의 조회된 주민등록 구성 비율에 따라 색 농도를 바꾼다. 연령 자료 미조회는 회색이며 0%로 채우지 않는다. 실시간 유동인구 연령 비율과 주민등록 거주자 구성을 섞지 않는다.

따릉이는 기존 공식 CSV/XLSX 업로드 자료를 사용하며 이 변경에서 전체 대여소 자동 API 수집은 추가하지 않았다. 주민등록 자료는 기존 생활환경 영역의 조회 버튼으로 불러오고 다음 실행 때 지도에 반영한다. 서울 전체 동네의 연령별 지도를 자동 조회하는 기능은 아직 없다.

## 실제 경계

대표점 주변 원은 동네 경계가 아니다. 화면 카드에도 이 사실을 표시한다. 실제 경계가 필요하면 사이드바 ‘지도 경계 자료’에 공식 WGS84 GeoJSON을 넣는다. FeatureCollection·Polygon/MultiPolygon을 지원하고 각 feature의 properties.legal_code가 서울 법정동 10자리 코드여야 한다. 닫힌 링·서울 좌표 범위·중복 코드를 검사한다. 매칭되는 선택 동네만 경계로 표시한다. 행정동 경계에 법정동 코드를 임의로 붙이지 않는다. 자료의 출처·기준시점 자체를 자동 검증하는 기능은 아니므로 원자료를 확인해야 한다.

공식 경계 API 및 자료: [서울 스마트맵 OpenAPI](https://map.seoul.go.kr/smgis2/division/viewOpenApi), [SGIS 경계 API](https://sgis.mods.go.kr/developer/html/newOpenApi/api/dataApi/addressBoundary.html). 현재 별도 경계 API 인증·자동 수집은 연결하지 않았다. [서울 실시간 도시데이터](https://data.seoul.go.kr/dataVisual/seoul/guide.do)의 주요 장소 단위는 모든 법정동 경계를 대신하지 않는다.

## 검증

전체 테스트 132개 통과. 직장·통근·선호 없이 예산 조회 가능, 잘못된 경계 코드/좌표 거부, 누락 연령 미확인 유지, 지도 데이터의 script 삽입 방지와 기존 기능 회귀를 확인했다. 생성 지도 JavaScript 문법 검사도 통과했다. 실제 브라우저에서 Kakao 도형 클릭·레이어 전환의 시각 검증은 후속 확인이 필요하다.

## 자동 자료 연결 보완 (2026-10-22)

기존 버전은 필터만 있고 최초 자료가 없어 비어 있었다. 현재는 서울시 공식 OA-13252의 2026년 6월 엑셀(seq=24)을 실제 내려받아 2,789개 위치를 기본 포함한다. 제외·중복 2행과 원본/정규화 해시·출처를 기록했다. 실시간 API 8088/443은 연결 시간 초과이므로 성공으로 표시하지 않고 공식 파일 스냅샷을 사용한다. 업로드는 선택적 자료 교체다. 공식 엑셀의 다중 행 헤더를 읽도록 로더도 수정했다.

실거래 선택과 별도로 지도 동네 선택을 제공한다. 초기 탐색 동네는 신당동이며 추천 결과나 사용자 조건으로 추정한 값이 아니다. 동네 변경 시 카카오 법정동 대표점과 지난달 주민등록 연령을 자동 조회한다. 성공한 공공 자료는 24시간 캐시하고 선택 동네 다시 불러오기 버튼으로 갱신할 수 있다. 위치/API 실패는 명시한다. 주민등록 단일 법정동 코드·월·연령 합계 검증을 유지한다.

지도에 선택 대표점 3km 내 대여소를 표시하고 20대 연령 색상을 초기 적용한다. 연령 선택 HTML의 닫힘 오류도 수정했다. 클릭 카드의 따릉이 개수는 500m 기준이므로 3km 표시 개수와 다르다. 실제 경계가 없을 때 색상 원은 대표점 주변 500m이며 서울 전체 연령 분포는 아니다.

실제 AppTest: 신당동 202609 주민등록 62,712명, 20대 11.0%·30대 16.4%·60대 16.6%, 3km 대여소 201개. [자동 자료 연결 기록](검증/지도_자동자료_실제연결.json). Python 테스트 135개, 지도 JavaScript를 Kakao/DOM 스텁으로 실행해 초기 색상·필터·영역 클릭을 확인했다. 브라우저 자동 제어가 Work 설정에서 비활성화되어 실제 Kakao 화면 클릭은 검증하지 못했다.
