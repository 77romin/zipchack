# 연령 구성의 초록–노랑–빨강 지도

기본 지도 색상은 특정 연령의 보라색 농도가 아니라 두 연령군 구성의 연속 색상이다.

- 청년군: 만 20~39세.
- 비교 연령군: 만 60세 이상. 60대·70대·80대·90대·100세 이상을 포함한다.
- 지표: `60세 이상 인구 / (20~39세 인구 + 60세 이상 인구)`.
- 지표 0은 초록(#16a34a), 0.5는 노랑(#facc15), 1은 빨강(#dc2626)이고 중간 값은 RGB 선형 보간한다.

두 비중이 같으면 노랑이다. 비중의 분모는 각 동네 총 거주자 수이며 색상 지표의 분모는 비교하는 두 연령군의 합이다. 0~19세와 40~59세를 색상 비교에서 제외한다. 평균 연령·인구 밀도·주거 적합성 점수가 아니다. 색이 붉다는 것이 살기 나쁘다는 뜻은 아니다. 나이대 기준은 이번 시각화의 프로젝트 정의이며 법정 고령자 정의가 아니다. 값이 없거나 두 군 합이 0이면 회색이다.

사용자가 참조한 [서울 생활인구 페이지](https://data.seoul.go.kr/dataVisual/seoul/seoulLivingPopulation.do)의 생활인구는 통신·공공 자료로 특정 시점·지역에 존재하는 인구를 추정한 통계다. 현재 구현은 기존에 실제 연결한 주민등록 거주자 통계를 사용한다. 생활인구를 수집한 것으로 표시하지 않으며 두 공간 단위·시점을 섞지 않는다.

## 사용

1. 지도에서 동네를 선택한다. 기본 연령 지도 모드는 ‘20~39세 ↔ 60세 이상 구성’이다.
2. 현재 동네의 원/경계가 구성 비중에 맞춰 색칠된다. 기존 개별 연령 비율 모드도 유지한다.
3. ‘같은 구 동네 색상 비교 불러오기’를 누르면 현재 동네와 법정동 코드순 최대 7곳을 추가 조회한다. 가장 가까운 8곳을 찾는 기능이 아니며 조회 실패 지역은 경고한다.
4. 비교 원을 클릭하면 동네 이름·비교 비율·주민등록 기준월을 확인한다. 다른 동네를 방문하면 그 동네도 세션의 비교 목록에 쌓인다. 지도는 같은 구·같은 월 자료만 함께 전달한다.

참고 영역은 선택 동네 대표점 반경 500m, 비교 동네 반경 350m다. 원의 면적·크기는 인구량을 나타내지 않는다. 선택 동네는 업로드한 법정동 경계가 있으면 실제 제공 도형을 사용한다. 비교 동네는 아직 원 표시이며 지역 전체 경계를 채우는 코로플레스 지도는 아니다. 원 사이의 빈 공간을 임의의 인구값으로 채우거나 공간 보간하지 않는다.

## 검증

초록/노랑/빨강 끝점·동일 비율 색 일치·누락 및 0분모 회색 처리를 테스트했다. 신당동과 같은 구의 8개 후보를 실제 조회해 성공한 6곳의 색상을 기록했다. [실제 조회 기록](검증/연령구성_색상비교_2026-10-23.json). 한 번의 조회 성공은 전체 서울 자료 확보를 의미하지 않는다.

현재 공개 API·문서 출처를 확인하고 기능 및 AppTest로 검증했다. 브라우저 자동 제어 비활성화로 실제 브라우저의 시각 검증은 별도 필요하다.
