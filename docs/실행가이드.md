# 집.착 실행 가이드

## 실행

프로젝트 폴더에서 다음 명령을 실행한다.

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

`.env.example`의 항목을 참고해 `.env`에 키를 입력한다. 실제 키는 커밋하지 않는다.
카카오맵 사용 설정을 켜고 JavaScript SDK 도메인에 실제 접속 주소(예: `http://localhost:8501`)를 등록한다.

## 현재 사용할 수 있는 기능

1. 직장·보증금·월세·탐색 반경·생활 선호를 입력하고 적용한다.
2. 직장을 검색하고 결과를 선택하면 지도에 직장 핀과 직선거리 반경이 표시된다.
3. 서울시 공식 따릉이 대여소 위치 CSV/XLSX를 업로드하면 반경 안의 대여소 핀·목록을 확인한다. 대여소 핀을 누르면 이름과 거리를 볼 수 있다. 실시간 재고는 사용하지 않는다.
4. 서울 열린데이터 키를 설정하고 공식 장소명/코드로 현재 상황을 조회한다. 혼잡도·추정 인구·상주 비율·연령 구성·대기환경과 각 기준 시각을 확인한다. 누락값은 0 대신 미제공으로 표시한다.

도시데이터의 조회 장소는 직장과 자동 연결되지 않는다. 제공되는 공식 장소 영역의 데이터이며 서울 전체 건물별 관측값이 아니다. 실시간 연령 구성은 거주민만의 연령 통계가 아니다.

따릉이 파일은 공식 제공 페이지에서 내려받는다: https://www.data.go.kr/data/15051893/fileData.do
허용 크기는 20MB다. 파일은 사용자 세션에서 읽고 프로젝트 폴더에 저장하지 않는다. 자료 기준일과 현재 운영 여부는 원본에서 확인한다.

## 아직 구현되지 않은 기능

실거래가 수집·주거 후보 순위·공원과 주민등록 연령 통계·레이어 색상·지도 연계 상담·Vector DB·문서 RAG·MMR·정량 실험은 후속 기능이다. 현재 챗봇은 인사말만 표시한다. 제휴 API는 사용하지 않으며 경로는 카카오맵 길찾기 바로가기 방식으로 연결할 예정이다. 앱 내부 이동시간 계산은 제공하지 않는다.

## 테스트

```powershell
.\.venv\Scripts\python.exe -B -m unittest discover -s tests -v
```

테스트의 위치·XML 값은 명시적인 테스트 전용 데이터다. 서비스에서 실제 조회 실패를 샘플 데이터로 대체하지 않는다. Streamlit AppTest는 Python 화면 흐름을 확인하며 실제 브라우저 지도 타일·JavaScript SDK 동작을 검증하는 것은 아니다.
