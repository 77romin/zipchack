# 동네 통합 정보 카드

지도에서 동네 경계, 대표점 이름 버튼 또는 대표점 마커를 누르면 팝업을 표시한다. 메인은 지도와 대화 구성을 유지한다.

| 항목 | 표시 기준 |
| --- | --- |
| 거래 | 현재 저장된 조회 결과와 같은 자치구의 법정동 이름을 대조한다. 예산 내 과거 계약 수와 실제 한 계약의 보증금·월세·계약일을 함께 표시한다. 현재 매물·호가로 표현하지 않는다. |
| 조회 상태 | 다른 자치구/미조회, 성공 자료 없음, 예산 미입력, 예산 내 0건, 부분 조회를 구분한다. |
| 따릉이 | 동네 기준점에서 500m 직선거리 안의 공식 위치 자료. 가까운 순 최대3곳 이름과 거리를 표시한다. 실시간 재고가 아니다. |
| 공원 | 같은 500m 기준의 서울 주요 공원 좌표. 모든 공원의 전수자료나 입구 기준 도보거리가 아니다. |
| 연령 | 클릭한 법정동 코드와 기준월이 같은 주민등록 자료의 인구·연령별 비율을 표시한다. 0명과 미확인을 구분한다. |
| 출처 | 거래 유형별 출처, 따릉이·공원·주민등록 공식 링크와 자료 시점을 제공한다. |

사이드바에서 선택한 동네는 조회된 대표점을 사용한다. 나머지 동네는 경계 좌표 평균점을 임시 기준점으로 사용하며 카드에 `동 경계 기준점(대략)`으로 표시한다. 개별 주택의 접근성이나 실제 도보시간을 뜻하지 않는다.

카드는 서울467개 법정동에 연결된다. 현재 조회된 자료를 재사용하며 클릭만으로 다른 자치구의 거래 API를 자동 호출하지 않는다. 새 조회 결과와 인구 자료는 지도 메시지에 반영되어 다음 클릭에 사용된다.

연령 그라데이션의 장식 레이어와 래퍼는 포인터 입력을 받지 않게 하고 대표점은 상단에 배치한다. 경계 클릭용 폴리곤은 매우 낮은 채움 불투명도(0.001)로 SDK 클릭 판정을 유지한다. 팝업 본문은 텍스트 노드로 렌더링하고 출처는 HTTP(S) 링크만 허용한다.

검증: 가격의 자치구·법정동 범위, 미조회/0건 구분, 부분 조회, 공원·대여소 거리, 0명 인구, 동별 카드 구분을 테스트했다. 실제 Chrome에서 신당동과 광희동1가 클릭, 팝업 내부 스크롤과 공식 출처 링크 표시를 확인했다.
