# P3와 LangGraph 검색·생성

실제 LangGraph 1.2.10의 StateGraph를 컴파일해 `START → retrieve → generate → END`로 실행한다. P1/P2는 문서 준비 단계이며 이 그래프의 별도 노드가 아니다.

```powershell
.\.venv\Scripts\python.exe scripts/ask_rag.py --item 1144010200 --question "공덕동은 어느 구이고 공덕역에 어떤 노선이 있나요?" --mode mmr
```

기존 색인과 GMS_KEY를 사용한다. 문서 확장이 필요하면 먼저 prepare_rag.py를 실행한다. 기본 출력 파일은 storage/rag_answer.json이며 질문·답변·근거 원문을 포함하므로 실제 사용자 질문 결과는 공유하지 않는다. 색인 비용·P1/P2 호출은 이 질의 실행 시간에 포함하지 않는다.

## 처리와 근거

- retrieve: 선택 법정동 메타데이터를 반드시 포함하고 해당 동네 외부 문서를 similarity 또는 mmr로 검색한다. 근거 번호·원문·유형·출처·기준시각을 유지한다.
- generate: P3(answer-v1)가 제공 근거만 사용해 JSON 답변을 생성한다. 메타데이터와 외부 문서 구분, 자치구의 다른 동네 특성 전이 금지, 근거 없는 가격·통근시간·매물 추정 금지, 부족한 자료에 대한 유보를 지시한다.
- 출력 검증: answer 문자열·abstained 불리언과 인용 번호를 검사한다. 근거에 없는 번호·직접 생성 URL·인용 없는 비유보 답변은 실패 처리한다. 실패한 답변을 정상 답변으로 반환하지 않는다.
- 출처 목록: 답변에 실제 등장한 근거 번호만 사용한다. 같은 문서의 인용 번호는 하나의 출처 아래 묶고 제목·유형·원문 링크·판 시각·기여자·라이선스를 보존한다.

형식 검증은 **인용이 실제로 주장을 뒷받침하는지 또는 답변의 사실 정확성**을 자동 보장하지 않는다. abstained는 모델이 출력하는 값이며 정량 평가에서 사람의 판정과 비교해야 한다. 번호 누락·틀린 번호 테스트와 사실성 평가를 구분한다. 원문 속 지시를 자료로 취급하도록 프롬프트에 명시하지만 별도의 보안성 검증이 완료됐다는 의미는 아니다.

명령행 독립 실행과 Streamlit 동네 근거 질문 화면에서 호출한다. 기존 조건 추천 대화는 별도이며 해당 대화가 이 그래프를 자동 호출하지 않는다. 동네별 기록은 화면에 보관하지만 이전 대화 문맥은 전달하지 않는다.

## 실행 기록

결과에는 retrieve/generate 실행 순서, 검색 상세, 인용 출처, 모델·P3 버전, 검색·생성·노드 합계·전체 실행 시간을 기록한다. 전체 시간은 그래프 호출 전부터 측정하며 노드 합계와 다를 수 있다. 한 번의 연결 확인 시간을 비교 성능 수치로 사용하지 않는다.

- [실제 MMR 답변](검증/RAG_LangGraph_실제답변.json): 공덕동 자치구·공덕역 노선 질문, 메타데이터와 위키 문서 인용.
- [근거 부족 질문](검증/RAG_LangGraph_근거부족.json): 현재 입주 가능한 특정 월세 매물 호수·연락처를 자료에 없다고 응답.

UML 원본·SVG, 화면 연결, 최소 5개 이상의 고정 질문에 대한 RAG 전후 비교, 유사도/MMR 정량 표·SVG는 이후 단계다. 이번 실행 기록은 정식 품질 검증이나 성능 비교 결과가 아니다.
