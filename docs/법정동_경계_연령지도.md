# 실제 동 경계를 채우는 연령 지도와 자전거 아이콘

연령 표시를 대표점 주변 원에서 **법정동 Polygon/MultiPolygon 내부 채색**으로 변경했다. 각 동의 경계가 맞닿는 단계 구분도(choropleth)이며, 개별 동 안에서는 같은 집계값을 사용한다. 기상 지도처럼 색으로 분포를 읽을 수 있지만, 실제 관측하지 않은 동 사이의 값을 보간하거나 풍향 애니메이션을 추가하지 않는다.

## 경계와 통계의 연결

- 경계: 국가공간정보포털(V-World) 원본의 공개 변환본 [KnellBalm/kr-admin-geojson](https://github.com/KnellBalm/kr-admin-geojson). 제공자 문서상 기준일은 **2023-07-29**이며 EPSG:5179에서 WGS84로 재투영·단순화한 자료다.
- 제공자는 원본·변환본을 출처 표시 조건으로 이용할 수 있다고 명시한다. 원출처와 변환자를 함께 표기하고 원본·정규화 SHA256 및 가공 과정을 sidecar에 기록했다. 공식 API가 직접 반환한 최신 경계로 표시하지 않는다.
- 서울만 추출하고 EMD_CD 8자리에 00을 붙인 법정동 10자리 코드와 동 이름을 행정안전부 현존 목록에 대조했다. **467개 모두 코드·이름이 일치**했다. 행정동으로 변환하거나 HJD_CD 필드로 조인하지 않는다. 코드 일치가 2026년 현재 경계 형상의 정확성까지 검증했다는 뜻은 아니다.
- 통계: 행정안전부 단일 법정동 주민등록 거주자, 현재 202609. 요청 코드·월·연령 합계 검증을 유지한다. 20~39세와 60세 이상 구성 비중의 색상 정의는 기존 [연령 구성 안내](연령구성_그라데이션.md)를 따른다.

## 화면 동작

처음 선택된 중구 신당동의 자치구 전체 **74개 동 경계**를 표시한다. 이번 개발 환경에서 74곳을 실제 조회해 68곳은 색상값을 확보했고 6곳은 미확인 회색이다. 경계는 모두 제공하고 인구 자료가 없다고 주변 값으로 채우지 않는다. 다른 자치구를 고르면 해당 구의 동 경계가 표시된다. 아직 인구를 조회하지 않은 동은 회색이며 ‘선택 자치구 전체 동의 연령 지도 불러오기’로 채울 수 있다.

선택 동네는 거래·따릉이·연령 정보 카드를 유지한다. 다른 동 경계를 클릭하면 동 이름·시점·연령 비중을 확인한다. 연령 비교용 반경 350m/500m 원은 제거했다. 직장 기준 탐색 반경은 별도 기능으로 남아 있으며 법정동 경계와 다르다.

따릉이는 Kakao 기본 파란 핀을 제거하고 **23px 초록색 원 안의 흰색 자전거 SVG**를 DOM CustomOverlay로 표시한다. 아이콘은 직접 작성한 벡터이며 외부 이미지나 폰트 다운로드가 없다. 대여소명이 접근성 이름·툴팁에 포함되고 클릭하면 위치 안내가 열린다. 기존 따릉이 표시 필터도 동일하게 작동한다. 같은 대여소가 시설 점과 중복 표시되지 않도록 해당 시설 점은 제외했다.

## 자료 준비와 검증

공유 경계 자료는 data/seoul_legal_boundaries.geojson과 source.json이다. 통계 원자료 캐시는 로컬 storage/population_YYYYMM.json이며 Git에 포함하지 않는다. 새 환경에서는 아래 명령으로 필요한 자치구를 준비한다. 실패한 동은 재실행할 때 다시 조회하고, 키는 저장하지 않는다.

```powershell
.\.venv\Scripts\python.exe scripts/prepare_age_map.py --district 11140
```

[중구 실조회 요약](검증/연령지도_구별조회_11140.json). AppTest에서 기본 앱을 실제 API/캐시로 실행해 예외 0개·주민등록 자료 68곳을 확인했다. 467개 경계 해시·코드 일치, 원 제거·자전거 오버레이 테스트와 지도 JavaScript의 Kakao/DOM 스텁 실행을 확인했다. 브라우저 자동 제어 비활성화로 실제 브라우저 시각·클릭 검증은 별도 필요하다.

## 경계 사이 색상 연결 (2026-10-23 후속 수정)

기본 연령 구성 모드는 동별 색 블록 대신 Canvas 합성 레이어를 사용한다. 동별 폴리곤을 지도 화면 좌표로 투영하고 색을 그린 뒤 24px blur로 인접 색을 혼합한다. 알려진 동들의 합집합 마스크(destination-in)를 적용해 미확인 동·지도 범위 밖을 색으로 추정하지 않는다. 미확인 동은 별도 회색으로 남긴다. 내부 구분선은 숨기고 투명한 폴리곤은 동 클릭 대상으로 유지한다. 따릉이 아이콘보다 아래 zIndex1, 정보창은 zIndex20으로 겹침을 구분한다.

지도 idle·확대/축소·컨테이너 크기 변경 때 재투영한다. zoom_start 동안 색상 이미지는 숨겨 어긋난 위치가 잠시 보이지 않게 한다. 24px는 화면상의 평활화 크기이므로 확대 수준에 따라 지리적 혼합 범위는 달라진다. 경계 근처의 색은 위치별 실측값이 아니며 인구 통계나 점수를 변경하지 않는다. 동 클릭 카드의 원래 수치가 판단 기준이다.

JavaScript 스텁 테스트에서 실제 캔버스 합성 분기·blur·미확인 영역 제한 마스크·경계선 제거 실행을 확인했다. 실제 브라우저의 시각 검증과는 구분한다.
