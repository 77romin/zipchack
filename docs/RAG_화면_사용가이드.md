# 동네 근거 질문 화면

Streamlit 실행 후 기존 조건 대화 아래의 **동네 근거에 질문하기**를 사용한다.

1. ‘질문할 동네’에서 서울 법정동을 고른다. 지도에서 선택한 법정동 코드가 확인되면 최초 기본 선택에 반영된다. 이후 선택이 다르면 ‘지도에서 선택한 동네로 질문하기’로 이동할 수 있다.
2. 유사도 또는 MMR 검색을 선택한다.
3. 구체적인 질문을 입력하고 ‘근거로 답변받기’를 누른다.
4. 답변의 근거 번호를 확인하고 ‘답변에 사용한 근거’에서 원문·자료 시점·문서 종류·위키 라이선스와 기여자를 확인한다.

기존 예산·통근 조건 대화와 문서 RAG 질문은 별도다. RAG 질문으로 예산이나 지도 필터를 자동 변경하지 않는다. 기존 구조화 API 응답을 이 문서 질문의 근거로 자동 주입하지 않는다.

대화 기록은 10턴까지 동네별로 이 세션에 보관한다. 동네를 바꾸면 그 동네의 기록만 보이고 다시 선택하면 복원된다. ‘이 동네 질문 기록 지우기’는 선택 동네 기록만 지운다. 세션 종료 시 기록은 보존되지 않는다. 질문·답변은 파일에 자동 저장하지 않는다.

현재 기록은 화면 표시용이며 이전 대화 내용을 모델에 전달하지 않는다. 질문은 독립 처리하므로 ‘그곳은?’처럼 앞선 문맥에 의존하는 질문 대신 동네와 대상을 명시한다. 외부 문서가 없는 동네는 메타데이터 범위만 확인할 수 있다. 문서 추가 수집(P1/P2)은 명령행에서 실행하며 화면에서 자동 수집하지 않는다.

색인이 없거나 키·네트워크·답변 형식 검증에 문제가 생기면 오류 안내를 표시하고 기존 대화는 보존한다. API 키·프롬프트 전문·원본 예외를 화면에 표시하지 않는다. 저장된 문서가 현재 매물·현재 운행·거주 적합성을 보장하지 않는다는 안내를 표시한다. 오래된 서버에서 새 모듈이 반영되지 않으면 기존 실행을 종료한 뒤 run.ps1로 다시 실행한다.

검증은 Streamlit AppTest로 동네별 기록 전환·삭제·검색 방식 전달·오류 비노출을 확인했다. 실제 GMS·Chroma·LangGraph 호출을 통한 화면 처리 결과는 [연결 기록](검증/RAG_Streamlit_실제연결.json)을 참고한다. 이는 실제 브라우저에서 화면 배치·스크롤·모바일 가독성을 확인한 검증과는 구분한다.
