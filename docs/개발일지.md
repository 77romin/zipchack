# 집.착 개발일지

## 2026-10-22 · 직장 중심 탐색 범위 완성

- 변경: 기존 반경 입력·저장 작업을 유지하고, 직장 핀과 탐색 원을 실제 지도에 표시했다.
- 이유: 지도 HTML을 `map_view.py`로 분리해 화면 코드와 지도 동작을 독립적으로 확장한다.
- 보완: 직장 재검색 때 이전 선택을 초기화해 새 결과에서 다른 직장이 자동 선택되지 않게 했다.
- 검증: 반경 단위·유효 좌표·키 삽입과 Streamlit 조건 입력·검색·재검색 시나리오를 테스트한다.
- 범위: 실제 통근시간 계산은 하지 않는다. 제휴 API 없이 카카오맵 길찾기 연결을 사용한다.

## 2026-10-22 · 따릉이 위치 파일 연결

- 변경: 공식 CSV/XLSX 업로드, 열 이름 정규화, 잘못된 좌표·중복 제외, 직장 반경 필터, 대여소 지도 핀·목록을 추가했다.
- 이유: 사용자에게 필요한 위치 정보만 사용해 실시간 재고 API 의존성을 없앤다. API 키 없이 원본 파일의 기준일을 확인하며 사용할 수 있다.
- 검증: UTF-8·CP949·XLSX, 상단 메모행, 결측·중복·비정상 좌표, 반경 거리, 업로드 이름의 HTML 삽입 차단을 테스트했다.
- 범위: 대여소가 가까운지 보여주며 자전거 재고나 실제 경로시간은 보장하지 않는다. 공공누리 출처를 함께 표시한다.

## 2026-10-22 · 서울 실시간 도시데이터 조회

- 변경: 공식 XML의 중첩 구조를 파싱하고 혼잡도·인구 범위·상주 비율·현재 연령 구성·대기환경·갱신 시각을 표시했다.
- 이유: 현재 상황 정보를 한 공급처에서 조회하되 상주 비율을 거주민 전체 수나 거주민 연령 분포로 오해하지 않게 한다.
- 보완: 누락값과 0을 구분하고 대체 데이터 경고를 표시한다. API 오류와 연결 오류에서 인증키 포함 URL을 노출하지 않는다.
- 검증: 중첩 XML·결측·0·대체 데이터·실패·시간 필드·화면 조회를 테스트한다. 실제 서울 키가 없어 인증된 실조회는 미검증이다.
- 운영: 조회 버튼을 누를 때만 호출하고 세션에 결과를 유지한다. 실시간 자료를 Vector DB나 장기 이력으로 자동 적재하지 않는다.
