# 집.착 개발일지

## 2026-10-22 · 직장 중심 탐색 범위 완성

- 변경: 기존 반경 입력·저장 작업을 유지하고, 직장 핀과 탐색 원을 실제 지도에 표시했다.
- 이유: 지도 HTML을 `map_view.py`로 분리해 화면 코드와 지도 동작을 독립적으로 확장한다.
- 보완: 직장 재검색 때 이전 선택을 초기화해 새 결과에서 다른 직장이 자동 선택되지 않게 했다.
- 검증: 반경 단위·유효 좌표·키 삽입과 Streamlit 조건 입력·검색·재검색 시나리오를 테스트한다.
- 범위: 실제 통근시간 계산은 하지 않는다. 제휴 API 없이 카카오맵 길찾기 연결을 사용한다.

## 2026-10-22 · 따릉이 위치 파일 연결

- 변경: 공식 CSV/XLSX 업로드, 열 이름 정규화, 잘못된 좌표·중복 제외, 직장 반경 필터, 대여소 지도 핀·목록을 추가했다.
- 이유: 사용자에게 필요한 위치 정보만 사용해 실시간 재고 API 의존성을 없앤다. API 키 없이 원본 파일의 기준일을 확인하며 사용할 수 있다.
- 검증: UTF-8·CP949·XLSX, 상단 메모행, 결측·중복·비정상 좌표, 반경 거리, 업로드 이름의 HTML 삽입 차단을 테스트했다.
- 범위: 대여소가 가까운지 보여주며 자전거 재고나 실제 경로시간은 보장하지 않는다. 공공누리 출처를 함께 표시한다.

## 2026-10-22 · 서울 실시간 도시데이터 조회

- 변경: 공식 XML의 중첩 구조를 파싱하고 혼잡도·인구 범위·상주 비율·현재 연령 구성·대기환경·갱신 시각을 표시했다.
- 이유: 현재 상황 정보를 한 공급처에서 조회하되 상주 비율을 거주민 전체 수나 거주민 연령 분포로 오해하지 않게 한다.
- 보완: 누락값과 0을 구분하고 대체 데이터 경고를 표시한다. API 오류와 연결 오류에서 인증키 포함 URL을 노출하지 않는다.
- 검증: 중첩 XML·결측·0·대체 데이터·실패·시간 필드·화면 조회를 테스트한다. 실제 서울 키가 없어 인증된 실조회는 미검증이다.
- 운영: 조회 버튼을 누를 때만 호출하고 세션에 결과를 유지한다. 실시간 자료를 Vector DB나 장기 이력으로 자동 적재하지 않는다.

## 2026-10-22 · 도시데이터 상세 항목 확장

- 변경: 인구 성별·연령 구성, 주차장, 지하철역, 전기차 충전소·충전기, 통합대기환경지수, 실시간 상권·업종·소비 구성을 6개 탭으로 제공한다.
- 이유: 인구·시설·환경·상권을 함께 확인해 사용자 생활 조건을 더 구체적으로 비교한다.
- 보완: 시설별 반복 XML을 행 단위로 파싱한다. 주차 실시간 미제공을 0이나 이용 가능으로 바꾸지 않고, 현재 날씨와 예보·인구 구성과 소비 구성을 분리한다. ERROR-335 설명을 공식 명세에 맞게 수정했다.
- 검증: 중첩 시설·중복 역·충전기 제한·0과 결측·예보와 관측 분리·비율 유효성을 테스트한다. 공개 sample 호출은 네트워크 시간 초과로 실패했고 인증키 실조회는 미검증이다.

## 2026-10-22 · 시설 레이어와 현재환경 선호 비교

- 변경: 주차장·지하철·충전소 레이어, 현재환경 중요도·현재 인구 연령대·상권 활동 선호, 장소 비교 목록과 점수 근거를 추가했다.
- 이유: 데이터를 나열하는 데서 나아가 사용자가 명시한 기준으로 조회한 장소들을 비교한다. 자동 대량 호출 없이 조회·추가한 결과를 세션 안에서 재사용한다.
- 보완: 제한 충전소를 공개 이용 가능으로 세지 않으며, 결측 지표가 있는 장소의 순위를 미확정으로 둔다. 성별은 정보 표시만 하고 점수에서 제외한다. 직장 선택 시 시설 핀은 반경 안으로 제한한다.
- 범위: 현재환경 비교 점수는 주거 적합도·치안·실제 매물 추천과 다르다. 상권 활동이 적다는 이유로 조용한 동네라고 단정하지 않는다.

## 2026-10-22 · 확장 데이터의 기획·실행 문서 반영

- README와 서비스 기획서에 새 데이터 항목·6개 탭·시설 레이어·현재환경 비교 기준·완료/미완료 범위를 반영했다.
- 최신 사용자 방침에 맞춰 ODsay·도보/자전거 제휴 호출 계획을 카카오맵 길찾기 화면 연결로 수정했다. 앱 내부 통근시간 자동 수신은 약속하지 않는다.
- 기획서 마지막 요구사항 대조표에 확장 기능과 남은 실조회·브라우저 검증을 추가했다. 실시간 도시데이터만으로 기존 문서 RAG 필수를 대체하지 않는다.
- README의 상세 기획서 경로를 현재 저장소 구조에 맞게 수정했다.
