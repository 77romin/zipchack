# 지도 화면 범위 기반 연령 자료 자동 조회

지도에서 다른 곳으로 이동하거나 확대·축소하면 화면 범위에 맞춰 연령 자료를 불러온다. 자치구 선택은 위치 이동용으로 유지하지만 통계 조회 범위를 제한하지 않는다.

## 구현

- 기존 단방향 st.iframe 대신 Streamlit v2 컴포넌트(map_component/bridge.js)를 사용한다. 내부 Kakao 지도에서 idle 후 500ms 대기해 남서·북동 좌표를 보낸다. 최초 표시에도 범위를 전달한다.
- 외부 컴포넌트는 내부 지도 프레임에서 온 메시지만 받아 Python에 전달한다. 지도는 컴포넌트 부모에서 온 자료 갱신 메시지만 받는다.
- Python은 좌표 숫자·유한성·순서를 검증하고, 법정동 폴리곤 외접 사각형과 화면 사각형이 겹치는 서울 동을 찾는다. 일부는 실제 화면보다 조금 넓게 조회할 수 있으나 보이는 동이 누락되지 않도록 한다. 서울 밖 동은 포함하지 않는다.
- 선택한 자치구가 달라도 조회한다. 같은 월의 성공한 자료는 세션에서 재사용하고 미조회만 최대 4개 동시 요청한다. 조회 실패는 60초 동안 재시도를 억제하고 회색으로 표시한다.
- 120개 동보다 넓으면 확대 안내를 표시하고 대량 API 호출을 보류한다. 전체 서울가 보이는 축척에서 모든 동을 한 번에 자동 조회하는 기능은 아니다.
- 서버가 새 자료를 받으면 기존 지도 프레임을 재생성하지 않고 연령 자료만 전달한다. 드래그한 위치와 줌·레이어 선택을 유지한다. 동네 선택이나 직장 변경으로 navigation이 달라지면 의도적으로 지도 프레임을 새로 만든다.
- 그라데이션과 클릭 카드의 자료는 갱신된 동별 값으로 다시 그린다. 자료가 없는 곳은 회색이다. 따릉이는 아래의 화면 범위 필터로 함께 갱신한다.

## 검증

단위·화면 테스트로 자치구를 넘는 범위 선택, 좌표 오류, 성공 자료 캐시, 넓은 범위 호출 방지를 확인한다. JavaScript 테스트로 범위 이벤트 전달·부모/자식 프레임 확인·자료 갱신 때 지도 프레임 유지·위치 선택 시 재생성을 확인한다.

실제 공식 API 연결은 [실행 기록](검증/지도범위_자동조회_2026-10-23.json)에 보관한다. 이 검증에서는 지도 범위 이벤트를 AppTest에 주입하고 API를 실제 호출했다. 브라우저 자동 제어가 비활성화되어 실제 마우스로 지도를 이동하는 검증과는 구분한다.

## 조회 상태와 재시도

- 개별 요청이 끝날 때마다 완료 수/요청 수를 진행률로 표시한다. 성공과 실패 모두 처리 완료에 포함하며, 조회 완료 후 자료 확인 수와 미확인 수를 별도로 표시한다.
- 지도 아래 `현재 화면 미확인 지역 다시 조회` 버튼으로 60초 대기 없이 실패·미조회 지역만 재요청한다. 성공한 동의 자료는 유지한다. 모든 동의 자료가 있으면 버튼은 비활성화된다.
- `미확인 지역과 원인 확인`에서 연결 실패·시간 초과, HTTP 오류, API 요청 거절, 해당 월 자료 없음, 응답 검증 실패를 구분한다. API 요청 거절만으로 키가 틀렸다고 단정하지 않는다. 원본 예외나 인증키는 노출하지 않는다.
- 등록 인구가 0명인 경우는 조회 실패와 구분해 비율 계산이 불가능함을 안내한다. 실패 대기 시간은 요청이 끝난 시점부터 계산한다.
- 성공 자료는 월별 공개 통계 스냅샷으로 저장한다. 2026-10-23 실제 Chrome 드래그 검증은 [개발일지](개발일지.md)와 [화면](검증/지도범위_브라우저확인.png)에 기록했다. 위의 AppTest 검증 이후 추가로 수행한 브라우저 검증이다.

## 따릉이 화면 범위 연동

- 공식 위치 스냅샷 전체(기본2,789곳)를 전달하고 지도 화면 안의 좌표만 초록 자전거 아이콘으로 표시한다. 선택 동네 대표점의 3km 제한을 적용하지 않는다.
- 지도 idle 시 범위를 갱신한다. 이미 만든 마커는 재사용하고 화면 밖 마커는 숨긴다. 이동마다 대여소 API를 호출하지 않는다.
- 한 화면 최대400곳을 표시하며 `표시 수/화면 안 전체 수`와 확대 안내를 제공한다. 필터를 끄면 전부 숨기고 다시 켜면 현재 범위로 복원한다. 업로드 위치 자료를 교체하면 기존 마커도 교체한다.
- 대여소 클릭에는 위치 자료이며 실시간 재고가 아니라는 안내를 표시한다. 위치가 바뀌었을 때 이전 선택 동네로부터 계산한 거리를 그대로 표시하지 않는다.
- 실제 Chrome에서 드래그에 따라37→65→77곳으로 갱신되고 필터가 켜짐/꺼짐을 확인했다. JS 테스트로 범위 교체·마커 재사용·업로드 교체·400곳 상한을 검증했다.
