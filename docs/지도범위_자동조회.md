# 지도 화면 범위 기반 연령 자료 자동 조회

지도에서 다른 곳으로 이동하거나 확대·축소하면 화면 범위에 맞춰 연령 자료를 불러온다. 자치구 선택은 위치 이동용으로 유지하지만 통계 조회 범위를 제한하지 않는다.

## 구현

- 기존 단방향 st.iframe 대신 로컬 Streamlit 컴포넌트(map_component/index.html)를 사용한다. 내부 Kakao 지도에서 idle 후 500ms 대기해 남서·북동 좌표를 보낸다. 최초 표시에도 범위를 전달한다.
- 외부 컴포넌트는 내부 지도 프레임에서 온 메시지만 받아 Python에 전달한다. 지도는 컴포넌트 부모에서 온 자료 갱신 메시지만 받는다.
- Python은 좌표 숫자·유한성·순서를 검증하고, 법정동 폴리곤 외접 사각형과 화면 사각형이 겹치는 서울 동을 찾는다. 일부는 실제 화면보다 조금 넓게 조회할 수 있으나 보이는 동이 누락되지 않도록 한다. 서울 밖 동은 포함하지 않는다.
- 선택한 자치구가 달라도 조회한다. 같은 월의 성공한 자료는 세션에서 재사용하고 미조회만 최대 4개 동시 요청한다. 조회 실패는 60초 동안 재시도를 억제하고 회색으로 표시한다.
- 120개 동보다 넓으면 확대 안내를 표시하고 대량 API 호출을 보류한다. 전체 서울가 보이는 축척에서 모든 동을 한 번에 자동 조회하는 기능은 아니다.
- 서버가 새 자료를 받으면 기존 지도 프레임을 재생성하지 않고 연령 자료만 전달한다. 드래그한 위치와 줌·레이어 선택을 유지한다. 동네 선택이나 직장 변경으로 navigation이 달라지면 의도적으로 지도 프레임을 새로 만든다.
- 그라데이션과 클릭 카드의 자료는 갱신된 동별 값으로 다시 그린다. 자료가 없는 곳은 회색이다. 따릉이 위치의 뷰포트 자동 재조회는 이 변경에 포함하지 않는다.

## 검증

단위·화면 테스트로 자치구를 넘는 범위 선택, 좌표 오류, 성공 자료 캐시, 넓은 범위 호출 방지를 확인한다. JavaScript 테스트로 범위 이벤트 전달·부모/자식 프레임 확인·자료 갱신 때 지도 프레임 유지·위치 선택 시 재생성을 확인한다.

실제 공식 API 연결은 [실행 기록](검증/지도범위_자동조회_2026-10-23.json)에 보관한다. 이 검증에서는 지도 범위 이벤트를 AppTest에 주입하고 API를 실제 호출했다. 브라우저 자동 제어가 비활성화되어 실제 마우스로 지도를 이동하는 검증과는 구분한다.
